# 基于 EasyX 实现的数据结构动画演示

> 本项目为数据结构课程期末大作业，使用 C++ 与 EasyX 图形库开发，旨在通过可视化动画的形式，帮助理解经典数据结构与算法的执行过程。

---

## 功能特性

- **10 组算法动画**：涵盖排序、遍历、图论、查找、分治等经典算法
- **交互式演示**：支持手动逐步演示与自动播放两种模式
- **步骤回溯**：可随时查看上一步或下一步的执行状态
- **算法详情**：每个动画均内置算法原理介绍弹窗，便于学习理解
- **UI设计**：圆角按钮、阴影效果、平滑的颜色状态标识
- **场景管理**：主菜单 → 选择器 → 动画演示 → 返回，流畅的页面切换

## 扩展指南

本项目采用**场景管理器**架构，具有良好的可扩展性，欢迎添加新的数据结构或算法动画。

### 添加一个新动画的步骤

1. **新建头文件**：复制 `project_10.h`，命名为 `project_11.h`
2. **实现动画类**：继承 `Project` 基类，重写以下方法：
   - `drawContent()`：绘制动画内容
   - `onNextStep()` / `onPrevStep()`：控制步骤前进/后退
   - `hasNextStep()`：判断是否还有下一步
   - `getAlgorithmTitle()` / `getAlgorithmInfo()`：算法介绍弹窗内容
3. **注册场景**：在 `SceneManager.h` 的 `SceneType` 枚举中添加新类型
4. **全局指针**：在 `main.cpp` 中声明并创建新场景实例
5. **绑定跳转**：在 `SelectorScene.h` 的按钮列表中添加新动画入口

无需修改按钮、弹窗、场景切换等基础逻辑，只需专注于动画本身的绘制与逻辑即可。

## 运行环境

### 方式一：Visual Studio 打开

1. 双击打开 `EasyX-期末大作业.sln`
2. 确认已安装 EasyX 库
3. 选择 `x64` 平台，点击**本地 Windows 调试器**运行

### 方式二：直接运行

- 进入 `x64/Debug/` 或 `可执行文件/` 目录，直接运行 `EasyX-期末大作业.exe`

## 操作说明

| 操作 | 说明 |
|-----|------|
| **鼠标点击** | 点击按钮进行页面跳转或控制动画 |
| **播放 / 暂停** | 左上角按钮，控制动画自动播放与暂停 |
| **上一步 / 下一步** | 底部按钮，手动控制动画执行步骤 |
| **详情** | 左上角蓝色按钮，弹出当前算法的原理介绍 |
| **返回** | 右上角红色按钮，返回动画选择器页面 |
| **滚动** | 在选择器页面，可使用鼠标滚轮浏览更多动画 |
